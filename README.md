# ☕ Coffee Shop Sales Analysis | Excel Data Analytics Project

## 📌 Project Overview

The **Coffee Shop Sales Analysis** project focuses on analyzing retail sales data to identify business trends, understand customer purchasing patterns, and generate actionable insights that can help improve coffee shop performance.

Using Microsoft Excel, this project explores sales performance across different time periods, store locations, product categories, and product types. The analysis helps understand peak sales hours, monthly revenue trends, and best-selling products.

## 🎯 Project Objectives

- Analyze sales trends by day of the week and hour of the day.
- Identify peak sales hours and high-activity periods.
- Calculate and analyze monthly sales revenue.
- Compare sales performance across different store locations.
- Evaluate average transaction value.
- Identify best-selling products based on quantity sold and revenue.
- Analyze sales distribution across product categories and product types.
- Support business decision-making through data-driven insights.

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data analysis and reporting
- **PivotTables** – Summarizing sales data across different dimensions
- **Excel Charts & Dashboard** – Visualizing sales trends and performance
- **Data Cleaning & Transformation** – Preparing data for analysis

## 📂 Dataset Information

The dataset contains **149,116 transaction records** covering the period from January 1, 2023, to June 30, 2023.

Key columns include:

| Column | Description |
|---|---|
| `transaction_id` | Unique transaction identifier |
| `transaction_date` | Date of the transaction |
| `transaction_time` | Time of the transaction |
| `store_location` | Location of the coffee shop |
| `transaction_qty` | Quantity of products purchased |
| `unit_price` | Price per unit |
| `product_category` | Category of the product |
| `product_type` | Specific type of product |
| `product_detail` | Product name or description |
| `Total Bill` | Total bill amount for the transaction |
| `Hour` | Hour extracted from the transaction time |
| `Day Name` | Day of the week |
| `Month Name` | Month of the transaction |

The dataset includes three store locations: Astoria, Lower Manhattan, and Hell's Kitchen.
